# 🌾 Smart Harvest Yield Prediction for Precision Farming

This is a complete, academic-grade **Final Year Project** that integrates Machine Learning with agricultural science to assist farmers in precision farming. It predicts crop yield (in tons/hectare) based on geographic location, crop type, seasonal intervals, and real-time soil/weather parameters, and provides actionable fertilizer and weather mitigation advice.

## 🚀 Step-by-Step Execution Guide

### Step 1: Install Dependencies
Open your command terminal inside the project directory and install the required Python libraries using:
```bash
pip install -r requirements.txt
```

### Step 2: Generate the Dataset
Run the data generator to create a realistic 5,000-record dataset of Indian crops, regions, weather levels, and nutrient scores:
```bash
python generate_dataset.py
```
This generates `dataset.csv` in the root of the project directory.

### Step 3: Run the Machine Learning Pipeline
Open and run all cells in `notebook.ipynb` to inspect the EDA plots, fit the model, and export the joblib files.
Alternatively, you can run the pipeline automatically via terminal to export the files:
```bash
python build_notebook.py
```
This script builds `notebook.ipynb` with code output cells intact and generates the following models files:
* `yield_prediction_model.joblib` (Trained Random Forest Regressor)
* `label_encoders.joblib` (Categories label encoders)
* `scaler.joblib` (Numerical feature scaling rules)
* `feature_columns.joblib` (Column alignments metadata)

### Step 4: Launch the Desktop Dashboard App
Execute the Tkinter Desktop Application:
```bash
python app_tk.py
```
This will open the **Smart Farming Control Center** dashboard UI.

## 🎨 Dashboard Design & Features (🌾 Smart Farming Control Center)
The desktop application is built with a custom professional theme and contains four primary navigation tabs:

1. **🌾 Yield Prediction Tab**:
   - **Interactive Input Form**: Select Indian State, District, Crop, Season, Soil Type, and adjust sliders for Rainfall, Temperature, Humidity, Soil pH, and N-P-K nutrient parameters.
   - **Dynamic District Update**: The district dropdown filters dynamically based on the state selected.
   - **Result Cards**: Instantly view the predicted yield (tons/hectare), total expected harvest weight (tons), and productivity category classification (Low, Moderate, High).
   - **Embedded Comparative Plot**: Shows a horizontal bar chart comparing what different crops would yield under your exact entered environment parameters, helping you choose the best-suited crop.

2. **🌱 Soil Analysis Tab**:
   - **pH Level Diagnostic**: Tells you if your soil is acidic, neutral, or alkaline, and suggests treatments (lime/gypsum).
   - **Nutrient Gap Visualizer**: Renders a Matplotlib double-bar chart showing your input N-P-K nutrient levels vs the optimal crop requirement levels.
   - **Chemical Remedy Calculations**: Dynamically computes and displays exact deficiency shortfalls in kg/ha and recommends specific fertilizer quantities (Urea, SSP, MOP).

3. **📊 Farming Insights Tab**:
   - **Climate Comfort Analysis**: Inspects whether the entered temperature and humidity lie inside the optimal climatic comfort zone of your crop.
   - **Weather Stress Alert**: Advises supplementary irrigation (drought/dry stress) or water drainage pathways (flooding/excess wet stress).
   - **Weather Comfort Envelope Scatter Plot**: Shows a visual comfort box containing the selected crop's healthy range, marking your input environment coordinates as a red star.

4. **🧠 About Project Tab**:
   - Explains the system architecture, features, and provides a quick revision card for the final year viva examination.

## 🧠 Academic Viva Questions & Answers

**Q1: What is Precision Farming and how does this project align with it?**
* **Answer**: Precision farming is an agricultural management system that uses data science and machine learning to ensure that crops and soil receive exact resource inputs (water, fertilizer, pH control) for optimal productivity. This project acts as a decision support system, analyzing local climate and soil factors to select crops and calculate chemical corrections.

**Q2: Why use a Random Forest Regressor over simple Linear Regression?**
* **Answer**: Crop yield response is non-linear and interactive. For example, a crop needs a "sweet spot" of temperature and rain; yields drop if conditions are too dry (drought) or too wet (flooding). Linear models cannot fit curves that increase and then decrease. Random Forest uses an ensemble of Decision Trees that splits parameters into hierarchical segments, capturing these non-linear thresholds and parameter interactions accurately.

**Q3: What are the target metrics of the model, and how did you measure accuracy?**
* **Answer**: The target variable is `yield` in tons per hectare. We evaluated the model using:
  - **Mean Absolute Error (MAE)**: Average absolute magnitude of predictions error.
  - **Root Mean Squared Error (RMSE)**: Penalizes larger deviations.
  - **$R^2$ Score**: Tells us the proportion of variance explained by features ($\approx 99\%$ on our realistic agronomic ruleset).

**Q4: How did you bridge the Jupyter Notebook (where the model was trained) with the Desktop App?**
* **Answer**: We used `joblib` to serialize the trained Random Forest model object, the standard scaler object, the column labels list, and the dictionary of LabelEncoder objects to `.joblib` files. The Tkinter GUI reads these files on startup and preprocesses user inputs using the identical scaler and label maps before running predictions.

**Q5: What are the main features of the soil diagnostic engine?**
* **Answer**: The engine assesses soil pH levels and computes the difference between current N-P-K inputs and the crop's optimal requirements. If a nutrient falls short, it calculates the equivalent commercial fertilizer required:
  - Nitrogen shortage $\rightarrow$ Urea ($46\% \text{ N}$)
  - Phosphorus shortage $\rightarrow$ Single Superphosphate (SSP, $16\% \text{ P}_2\text{O}_5$)
  - Potassium shortage $\rightarrow$ Muriate of Potash (MOP, $60\% \text{ K}_2\text{O}$)
